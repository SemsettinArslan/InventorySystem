# InventorySystem

# 🧰 Unity Envanter Sistemi

Bu proje, Unity ile geliştirilen bir **2D envanter sistemi**dir. Sistem; ekipman slotları, eşya slotları, eşya bilgileri, oyuncu statları gibi temel öğeleri içerir.

---

## 🧱 Özellikler

- 🎒 **Eşya Slotları (Inventory Slots):** Oyuncunun genel eşyaları sakladığı slotlardır. 
- 🪖 **Ekipman Slotları (Equipment Slots):** Oyuncunun üzerine takabileceği ekipmanları yerleştirildiği özel slotlardır.
- ℹ️ **TipData Paneli:** Bir eşyanın üzerine tıklandığında gösterilen eşyaya ait isim, açıklama, nadirlik, tip gibi bilgilerin yer aldığı paneldir.
- 📊 **Stat Paneli:** Oyuncunun güncel istatistiklerini gösterir. Ekipmanlar takıldığında bu istatistikler güncellenir.
- 📦 **JSON Tabanlı Veri Yapısı:** Eşyalar dış bir JSON dosyasında tutulur, kolayca güncellenebilir.
- 🔒 **Slot Tip Kontrolü:** Zırhlar sadece zırh slotlarına, silahlar sadece silah slotlarına takılabilir.
